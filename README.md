## Installation

1. Clonez le dépôt
  ```bash
  git clone https://github.com/WebScanner-X.git
  ```

2. Installation des dépendances nécéssaires
   ```bash
   pip -r install requirements.txt
   ```

3. Lancez l'application
   ```bash
   python WebScanner-X
   ```

## Installation 🔧

1. Clonez le dépôt
  ```bash
  git clone https://github.com/inza57765-sketch/WebScanner-X.git
  ```

2. Installation des dépendances nécéssaires
   ```bash
   pip install -r requirements.txt
   ```
3. Entrez dans le dossier de WebScanner-X
   ```bash
   cd WebScanner-X
   ```
4. Lancez l'application par defaut

   ```bash
   python WebScanner-X
   ```
## Paramètres ️⚙️

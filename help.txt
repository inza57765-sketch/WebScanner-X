============================================================
                     WebScanner-X
============================================================

Outil CLI d'analyse de serveurs Web.

UTILISATION
-----------

    webscan [COMMANDE]


OPTIONS DISPONIBLES
--------------------

    --scan <URL>
        Lance l'analyse d'une cible Web.

    --version
        Affiche la version actuelle de WebScanner-X.

    --readme
        Affiche le README du projet.

    --tree
        Affiche l'arborescence du projet.

    -h, --help
        Affiche cette aide.


EXEMPLES
--------

    webscan --scan https://example.com

    webscan --version

    webscan --readme

    webscan --tree
